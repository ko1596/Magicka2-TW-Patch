# 開發紀錄：把《魔法對抗2》變成台灣繁體中文

這份文件記錄這個補丁從無到有的過程：遇到什麼問題、當下怎麼想、最後怎麼決定。技術細節另外整理在 [TECHNICAL.md](TECHNICAL.md)。

整個專案是我和 AI 程式助理（Anthropic 的 Claude，透過 Claude Code）一起完成的：逆向分析、寫工具、批次審稿大多由 AI 執行，我負責實際進遊戲測試、截圖回報問題、決定用詞和取捨。很多決定是在遊戲裡看到畫面之後才做出來的，所以下面會常常出現「進遊戲一看才發現……」。

---

## 0. 起點：手上只有一包遊俠的簡體漢化

《Magicka 2》官方沒有中文。網路上找得到的中文化是遊俠網（ALI213）做的簡體中文補丁，裝了可以玩，但：

- 是簡體字，而且是中國用語（視頻、默認、設置……）。
- 翻譯品質參差不齊，很多句子是照字面直譯，遊戲裡大量的英文梗都不見了。

我想要的是「台灣人玩起來很自然」的版本。一開始的想法很單純：簡轉繁，順便修一下用語。後來才發現這件事比想像中深很多。

## 1. 先搞懂遊俠是怎麼漢化的

第一步是研究這包補丁到底做了什麼。補丁裡只有幾個檔案：

```
engine/PhysX3_x86.dll       （被改過的物理引擎 DLL）
engine/ali213/ali213.dll
engine/ali213/ali213.d02    （160 MB）
engine/ali213/ali213.d12    （文字）
```

逆向之後弄清楚整個機制：

1. **借 PhysX 上車**：遊戲啟動時一定會載入 `PhysX3_x86.dll`。遊俠在這個 DLL 裡挖了一段程式碼空間（code cave），讓它順便 `LoadLibraryA(".\ali213\ali213.dll")`。所以 Steam 一驗證檔案、PhysX 被換回原版，漢化就整個失效。
2. **攔截畫字**：`ali213.dll` 攔截 Direct3D 11 建立貼圖的函式，遊戲要畫字的時候，把中文字從自己的字型圖集換進去。
3. **字型圖集**：`ali213.d02` 是一張超大的字型圖，照 GBK 字集排列，每格 42 像素、每列 190 字。這代表**只有 GBK 裡有的字才畫得出來**。
4. **字典**：`ali213.d12` 是文字檔，每條長這樣：

   ```
   xfhsm_res_No.00000123
   xfhsm_res_ENG_Start
   id=6E237DFFh
   xfhsm_res_ENG_End
   xfhsm_res_CHI_Start
   公 羊
   xfhsm_res_CHI_End
   xfhsm_res_Remark00_Start
   Ram
   xfhsm_res_Remark00_End
   ```

   中文字後面都多一個空格，這點後面會一直困擾我。

這時候我就決定了一個原則：**不要動遊俠的程式，只改字典**。字典是文字檔，可以重複產生；程式碼動了就很難維護。

## 2. 第一版工具：可以重做的簡轉繁

我要的不是「轉一次就算了」，而是可以一直調整、隨時重新產生的流程。所以工具的核心設計是：

- 第一次執行時，把遊俠的簡體字典備份成 `ali213.d12.chs`。
- 之後**每次都從這份簡體備份重新轉換**，不會在繁體上再轉一次（那樣錯誤會累積）。
- 所有的調整都存在設定檔裡：OpenCC 轉換模式、詞彙替換表、逐條手動修改。

簡轉繁用 OpenCC 的 `s2twp`（台灣正體＋台灣用語）。介面用 PySide6 做，開發環境用 uv。

第一版的表格用 `QTableWidget`，2700 條一載入就卡住，改寫成 Model/View 架構才順。

OpenCC 也有它的問題：它太積極了，會把不該轉的詞也轉掉。例如冒出「計程車兵」這種莫名其妙的詞，或是「位元」「型別」「擴充套件」這種只在電腦語境才對的用語，出現在奇幻遊戲裡就很怪。這些都要用詞彙替換表一個一個修回來（目前共 57 組）。

## 3. 用語審查：比想像中多

轉完之後一條一條看，中國用語和誤譯多到嚇人。幾個印象比較深的：

- **「河蟹」**：我看到這個詞嚇了一跳，查了英文才發現原文只是 crab（螃蟹）。
- **Wizard 和 Lightning**：原本混用「巫師／法師」、「電／閃電」。如果整批替換，很容易誤傷其他詞，所以一條一條改，最後統一成「巫師」和「閃電」。
- **全形數字**：有些數字變成全形，要改回半形。
- **Steam Controller**：要不要翻成「Steam 控制器」？最後決定保留英文，因為台灣玩家就是這樣叫。
- **語言選單**：Español、Deutsch 這些我一度想翻成中文，後來想通：語言選單是給「看得懂那個語言的人」用的，應該保留原文。

## 4. 第一次進遊戲：一堆意想不到的問題

在工具裡看起來都對，一進遊戲才發現問題一堆。

**英文字和中文字疊在一起。** 像「Boss時間試煉」，B-o-s-s 最後一個 s 會跟後面的中文字疊在一起。原因是遊戲用英文字型畫英文、遊俠用中文字型畫中文，兩邊算寬度的方式不一樣。解法是：英文字母或數字後面接中文字時，自動補一個半形空格。

**置中會歪。** 標題畫面那排「按 A 開始」整排偏左。原因是引擎用英文字型去量中文字的寬度，量錯了。我試過把中文字後面的空格拿掉，結果字直接疊成一團，原來那些空格不只是斷行用，也負責撐開字距。最後判斷這個要改到引擎和遊俠程式的溝通層才修得好，代價太高，放棄。

**「獨」這個字壞掉了。** 它在圖集裡有，但遊戲裡會被拉寬、變模糊，應該是遊俠的字形資料壞了。只能在所有譯文裡避開「獨」：「獨角獸」改「一角獸」、「Independence Day」改「互助節」、「單打獨鬥」改別的說法。工具也會自動警告。

**多人連線的玩家名稱、房間名稱是亂碼。** 那些元件根本沒被遊俠攔截到，修不了。同樣的原因，`%s guest %d`（「某某的訪客」）翻成中文也會變亂碼，只能保留英文。

**很多字串根本沒翻到。** 遊戲裡到處冒出英文，例如啟動時一閃而過的「Checking…」。遊俠的字典只收了一部分。

## 5. 補上遊俠漏掉的字串

要補字串，得先知道遊戲裡到底有哪些字串、它們的 ID 是什麼。

遊戲用的是 Bitsquid／Stingray 引擎，資源都打包在 `data/` 裡一堆 16 位數編號的檔案。拆開之後找到字串表，英文都在裡面。ID 的算法最後也逆出來了：**字串內部名稱的 MurmurHash64A 雜湊（種子 0）取前 32 位元**。

有了這個，就能從資源包裡反查出每個 ID 對應的內部名稱，例如 `id=E1E6A7C6h` 是 `joa_3_1_4_outpost1_humanSP`。2751 個 ID 裡反查出了 2383 個，存在 `translation/keys.json`。

反查出內部名稱是整個專案的轉捩點。它讓我後來能：

- 補上遊俠漏掉的 132 條字串。
- 知道每句話是**誰說的**、在**哪一章哪一段**（`joa_3_1_4_outpost1_human` 就是第 3 章、某個前哨站、人類士兵說的第 1 句）。
- 知道哪些是**單人版**、哪些是**多人版**（SP／MP 結尾）。
- 依類別分類：法袍、武器、神器、製作名單、設定……

另外發現 `ali213.dll` 查字典時是依 ID 排序做二分搜尋，所以新增的條目一定要插在正確的位置，整份重新編號。

## 6. 字幕超出框

劇情對話一長就超出對話框。遊戲引擎只會在空格處斷行，中文沒有空格，所以遊俠才在每個中文字後面加空格。但有些元件（例如角色頭上的對話泡泡）根本不會自動斷行。

這個試了好幾輪：

- 每 36 字斷一行：對話框還是爆。
- 每 20 字斷一行：過場動畫字幕變成四五層，擋住畫面。
- 最後的做法：**依內部名稱判斷是哪一種文字**。角色對話用窄的（26 字），過場字幕、說明框用寬的（40 字）。斷行也改成「平均分配」，而且盡量斷在標點後面，避免最後一行只剩一兩個字，也不會把「——」或人名中間的「·」拆開。

## 7. 中文標題標誌

標題畫面的「MAGICKA 2」我想換成中文。我用 AI 生圖做了一個同風格的「巫師2」標誌。

一開始想走遊俠的貼圖替換機制，結果在遊戲裡沒效果。改成直接修改遊戲資源包：找到標誌的 DDS 貼圖（660×168，BGRA），把像素換掉、重新壓縮那幾個 64 KB 區塊。

改完一開始也看不到，因為標題畫面讀的是**開機時最先載入的另一個資源包**，裡面還有一份副本。兩份都改之後才成功。解析度也反覆調了幾次（原圖比例和 660×168 對不上）。看到標題變成「巫師2」的那一刻真的很爽。

## 8. 地圖地名：做了，然後放棄

世界地圖上的地名（Boring Bay、Midgård……）是畫在貼圖上的。我把原圖抽出來，請 AI 生成中文版，再寫工具套回去。

生圖這段花了很多時間：AI 一直改掉原本的風格。我發現原圖其實是深藍海洋上、帶著像海浪泡沫的模糊白邊，調整提示詞之後終於做出還不錯的「米德嘉德」。

但實際放進遊戲看，不管怎麼調都和原本的美術格格不入，反而破壞了地圖的質感。最後決定**全部還原，這部分不做**。工具和原圖都留著，也許以後有更好的方法。

## 9. 裝備名稱：放回情境才看得懂

法袍顏色「香瓜」，可是袍子明明是西瓜花紋。一查，「Melon」被翻成香瓜，「Choco Peppercorn」被音譯成「喬科佩珀康」，「Grape Viol」變成「格拉佩·維奧爾」：普通的英文單字被當成人名音譯。

這類問題單看字串很難發現，要放回遊戲畫面才知道。後來有了內部名稱，才能把「同一件裝備的名稱和說明」、「同一個神器的各個選項」放在一起看。像神器「Video Mode」的選項 Sweden、Video Boy、Last Gen，原本被翻成「瑞典」「影片小子」「上一代」。放在一起看才知道它們是**畫面濾鏡**，改成「瑞典風」「老掌機風」「上世代畫質」。

還有一些是要查資料才確定的：

- **Pit Manager**（使魔）原本叫「飛翼小惡魔」。查了玩家攻略才知道牠是會飛的小惡魔，能力是**隨機**強化元素。名字是雙關：Pit 是地獄深淵，Pit boss 是賭場的賭區主管。最後叫「地獄荷官」。
- **Familiar**：原本叫「魔僕」。台灣 ACG 的標準說法是「使魔」（《零之使魔》的英文就是 Zero's Familiar）。
- **Bananas**（最難的神器組合）：英文 go bananas 是「抓狂」的意思，但畫面上的圖示就是香蕉，最後保留「香蕉」。
- **地圖上的木馬**：場景內部名稱叫 `dalahast`，瑞典文的「達拉木馬」。

## 10. CPU 100%：意外發現的引擎問題

玩的時候發現 CPU 飆很高。社群的解法是「到工作管理員把遊戲限制在兩個核心」，但那只是治標。我一開始懷疑是漢化造成的，所以認真查了一下。

1. 先看 `ali213.dll`：它沒有自己開執行緒，鎖也都是「搶不到就跳過」的寫法，不像是兇手。
2. 寫腳本抓遊戲每條執行緒的 CPU 時間：整個遊戲吃掉約 8.7 顆核心。其中 **18 條引擎工作執行緒**各吃 35～45%，`ali213.dll` 只佔取樣的 0.5%。
3. 反組譯那段工作迴圈，發現引擎的工作執行緒沒事做時會**原地空轉，累積滿 1 毫秒才休眠**。遊戲每一幀都會派好幾批工作，執行緒幾乎每次剛要睡就又被叫醒。引擎依邏輯處理器數量開執行緒，我的 i7-12700K 有 20 個，就有將近 20 條一起空轉。

修法是把那個「1 毫秒」改掉。要特別小心的是，**派工端也用同一個門檻判斷「這條執行緒睡了沒、要不要叫醒」**，兩邊一定要一起改，不然執行緒睡著了卻沒人叫醒，遊戲會卡死。

| 設定 | 整體 CPU（主選單） |
|---|---|
| 原版 | 約 870% |
| 空轉 0.1 毫秒 | 約 600% |
| 不空轉（目前採用） | 約 330% |
| 實際對戰中 | 約 276% |

（100% 等於一顆核心跑滿。）改完玩起來很順，沒有變卡。總共只改了 exe 裡 6 個位元組。

## 11. 審稿：一輪比一輪深

文字的部分前後審了很多輪，每一輪換一個角度，因為每次都會發現上一輪的盲點。

**第一輪：全文掃描（606 條）。** 2691 條全部用同一套標準檢查：台灣用語、術語統一、格式代碼有沒有壞、明顯誤譯。這輪抓到最嚴重的問題，例如排行榜通知的 `%s`／`%d` 順序被調換（可能讓遊戲當掉），還有一條變成亂碼的「拉格納ÖK」。

**第二輪：梗（224 條）。** 我在遊戲裡看到「絕好的一天」（Mighty fine day，其實就是「今天天氣真好啊」），還有一句諺語被翻得莫名其妙，才發現**原本的譯者完全沒在處理梗**。Magicka 的對白到處都是：

- 英文諺語亂拼：「你可以把馬牽到水邊，但不能折斷牠的背」，其實是「牽馬到水邊」加上「壓垮駱駝的最後一根稻草」。改成讓中文讀者也看得出是兩句諺語硬拼：「你可以把馬牽到水邊，但壓垮牠的永遠是最後一根稻草。」
- 雙關：「mush room」（much room）→「它們『菇』且算是很省空間的啦！」；「no truffle」（no trouble）→「它們其實很無『菇』，一點也不麻煩！」
- 電影和遊戲台詞：薩爾達「It's dangerous to go alone」、魔戒「You shall not pass」、火箭隊、Monty Python、駭客任務「沒有湯匙」、福爾摩斯「Elementary」……

**第三輪：依分類（319 條）。** 有了內部名稱之後，把同一類的字串放在一起看。這輪抓到很多「單看沒錯、放回情境就錯」的問題：按鈕「Clear」被翻成「清晰」、挑戰結果「Strong Troll defeat」被翻成「擊敗強壯巨魔」（其實是挑戰失敗，意思整個反了）、個性選項「Hip」被翻成「臀部」（其實是時髦）。

**第四輪：單人／多人版、對話連貫（約 150 條）。** 同一句台詞有單人版和多人版，之前分開修，結果兩邊用詞對不上。把同一段對話串起來讀，也抓到人名其實是在講髮型（mullet 是鯔魚頭）、代名詞錯（巫師用「他」、螃蟹用「牠」）這類問題。

**第五輪：當劇本讀（82 條）。** 把每一章依場景排好、標上說話者的中文名，從頭讀到尾。這輪處理的是角色口吻（弗拉德的自大、瓦拉的冷淡、獸人的粗魯）和笑點的節奏（先鋪陳、後轉折）。

最後總共手動修改了 1675 條，佔全部 2691 條的六成以上；另外新增了 132 條遊俠沒翻到的字串。

## 12. 我學到的事

- **一定要進遊戲看。** 工具裡看起來對的東西，進遊戲常常不對。很多最重要的修正（濾鏡、西瓜、置中、斷行）都是看到畫面才發現的。
- **譯文需要情境。** 單看一個詞沒辦法判斷翻得對不對。內部名稱是整個專案最值錢的發現。
- **每次都從原檔重新產生。** 所有修改都是「設定」，不直接改結果，所以可以一直反悔、一直調整。
- **知道什麼時候該放棄。** 地圖地名、置中偏移、多人名稱亂碼，都是評估過後決定不做的。
- **梗比字面重要。** 這款遊戲的靈魂是它的幽默。字面正確但不好笑的翻譯，等於沒翻。

## 13. 還沒解決的

- 多人連線的玩家名稱、房間名稱有中文會亂碼（遊俠的攔截沒涵蓋那些元件）。
- 部分置中文字會偏一點（引擎用英文字型量中文寬度）。
- 滑鼠按鍵名稱、伺服器公告不在字典裡，翻不到。
- 「獨」字顯示壞掉，只能避開。
- 世界地圖上的英文地名（決定保留原美術）。

如果你有辦法解決其中任何一個，非常歡迎開 Issue 或 PR。
