# Magicka 2 台灣繁體中文化補丁

把《Magicka 2》（魔法對抗2）的中文化，從遊俠網（ALI213）的簡體中文版，轉換並全面重新潤飾成**台灣繁體中文**。

《Magicka 2》繁體中文補丁／中文化／漢化／繁中，又譯《魔法對抗2》《魔能2》，中文標題為「巫師2：咒語重修班……啟動！」。也收錄遊戲 CPU 使用率 100% 的修正。

> **本補丁是以遊俠網（ALI213）的《魔法對抗2》簡體中文漢化補丁為基礎改作而成。**
> 顯示中文的技術（`ali213.dll`、字型圖集）與最初的翻譯都來自遊俠漢化組，在此致上感謝。
> 本專案不包含、也不散布任何遊俠的檔案，使用前請先自行安裝遊俠的簡體中文補丁。

## 內容

- **台灣繁體中文文本**：全部約 2700 條字串。
  - 改用台灣用語（影片、預設、設定……），術語全面統一。
  - 手動重新翻譯或潤飾超過 1600 條，佔六成以上。原翻譯大量漏掉的英文梗、雙關、電影台詞，都盡量用台灣玩家看得懂的方式翻出來。
  - 補上遊俠漏翻的 132 條字串。
  - 修正會讓遊戲顯示錯亂的格式錯誤。
- **中文標題標誌**（可選）：標題畫面換成「巫師2」中文標誌。
- **CPU 使用率優化**（可選）：修正遊戲在多核心 CPU 上空轉、吃滿 CPU 的問題。實測 i7-12700K 從約 870% 降到約 330%（100% 等於一顆核心跑滿），玩起來沒有變卡。

## 安裝

1. 在 Steam 安裝《Magicka 2》。
2. 安裝**遊俠網的《魔法對抗2》簡體中文漢化補丁**，確認遊戲能顯示簡體中文。補丁可以在巴哈姆特 Magicka 板 Ben5762 的[這篇文章](https://forum.gamer.com.tw/C.php?bsn=18481&snA=486)下載。
3. 到 [Releases](../../releases) 下載 `Magicka2-TW-Patch.exe` 並執行。
4. 程式會自動找到遊戲位置。勾選要套用的項目，按「套用」。

請先關閉遊戲再執行。

### 瀏覽器或 Windows 跳出警告？

安裝程式沒有付費的數位簽章，剛發布的版本下載的人還不多，所以可能會看到警告。這是正常現象：

- **Edge 顯示「不常下載」**：在下載提示按「⋯」→「保留」→「顯示更多」→「仍要保留」。
- **Windows 顯示「Windows 已保護您的電腦」**：按「其他資訊」→「仍要執行」。

想確認檔案安全的話：每個版本的 exe 都是由 GitHub Actions 依照本 repo 公開的原始碼自動打包，Release 頁面附有 SHA-256 校驗碼與 GitHub 的建置來源證明，可以用 `gh attestation verify Magicka2-TW-Patch.exe -R ko1596/Magicka2-TW-Patch` 驗證。也可以照 [技術說明](docs/TECHNICAL.md#開發環境) 自己從原始碼打包。所有修改都可以還原：取消勾選某一項再按「套用」，就會還原那一項；按「全部還原」則回到遊俠簡體版加上 Steam 原版檔案。

### Steam 更新或「驗證遊戲檔案完整性」之後

Steam 會把遊俠改過的 `PhysX3_x86.dll` 換回原版，中文就會消失。請重新安裝遊俠補丁，再執行一次本程式。

## 已知問題

- 多人連線的玩家名稱、房間名稱如果有中文，會顯示亂碼（遊俠補丁的限制）。
- 部分置中的文字會稍微偏一邊。
- 「獨」這個字在遊戲裡顯示壞掉，所以譯文刻意避開這個字（例如「一角獸」）。
- 世界地圖上的地名保留英文原美術。
